SkillPath Navigator

A validated data pipeline and REST API over a job–skill dataset

SkillPath loads a fixed snapshot of entry-level job postings into a relational database and exposes skill-demand and job-matching analyses through a Django REST Framework API, with a browser interface on top.

It began as a coursework API. I then rebuilt the data loading as a validated ETL command, made the application run on PostgreSQL as well as SQLite, added Docker Compose, set up GitHub Actions to run every test against PostgreSQL 16, and deployed a public demo on Render.

Phishing Detection: signal or artifact?

What a high score does and does not tell you about a model

I parsed two raw email corpora with different on-disk formats into one record structure, deduplicated before splitting, balanced the classes and created stratified train, validation and test sets. The final model reached an F1 of 0.97–0.998 on the held-out test set.

The investigation was about why. A single linear unit already scored almost as well, and SHAP showed that 18 of the 25 most influential tokens in the model that saw email headers were routing and source artifacts: it had largely learned which dataset an email came from. On other benchmark corpora, the body-only model’s recall fell from 0.97 to 0.38.
